# Simple Interest Calculator

## Description
This is a Simple Interest Calculator project. It is a shell script that calculates Simple Interest based on Principal, Rate of Interest, and Time.

Simple Interest is the interest calculated on the principal amount. It is a quick and easy method to calculate interest on a loan or investment.

## Formula
Simple Interest = (Principal * Rate * Time) / 100

Where:
- Principal (P) = Initial amount of money
- Rate (R) = Rate of Interest per year in percentage
- Time (T) = Time period in years

## How to Use
1. Clone this repository
2. Run the script file `interest.sh`
3. Enter Principal amount when asked
4. Enter Rate of Interest when asked
5. Enter Time in years when asked
6. The calculator will display the Simple Interest

## Example
If Principal = 1000, Rate = 5%, Time = 2 years
Simple Interest = (1000 * 5 * 2) / 100 = 100
