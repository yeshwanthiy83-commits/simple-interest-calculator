# Contributing to Simple Interest Calculator
All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute
### Bug Reports
Bug reports are welcome. If you find a bug, please open an issue and describe what happened, steps to reproduce, expected behavior.

### Bug Fixes
Bug fixes are welcome. Fork the repository, create a new branch, fix the bug, commit, push, open a Pull Request.

### Documentation Improvements
Documentation improvements are welcome. If you find a typo or unclear explanation in README.md, please improve it and open a Pull Request.

### Enhancements and Ideas
Enhancements and ideas are welcome. If you have an idea to make the calculator better, please open an issue to discuss it first, then submit a Pull Request.

## General Guidelines
1. Fork the repository
2. Create a new branch
3. Make your changes
4. Commit with clear message
5. Push and open a Pull Request
6. Be respectful in discussions

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.
